# Contributing

Thank you for helping improve Echo.

1. Create a branch from `main`.
2. Keep credentials and personal training material out of commits.
3. Run `npm ci`, `npm run mobile:build`, and relevant tests before opening a PR.
4. Describe user-facing behavior changes and include screenshots for UI work.
5. Keep AI identity disclosure and consent safeguards intact.

Bug reports should include the Android version, app version, reproduction steps,
and sanitized logs. Never attach API keys, private conversations, voice samples,
or identifiable photos.
